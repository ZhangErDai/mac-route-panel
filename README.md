# 本机路由管理

macOS 本地 IPv4 路由管理网页：查看路由、开启/关闭、添加主机或网段路由，以及一键关闭后台。Python / FastAPI / Uvicorn 后台，原生 HTML / CSS / JavaScript 前端。

## 启动

### macOS 程序版

已生成 `dist/本机路由管理.app`（Apple Silicon / arm64）。双击程序会启动本地后台并打开浏览器，不需要另装 Python 或运行终端命令。可以将整个 `.app` 拖到“应用程序”目录；不要单独移动 `Contents` 内的文件。

程序版重复启动会重新打开现有后台的网页，兼容通过 `启动.command` 启动的旧版后台。此时继续使用现有后台和它的配置；要切换到程序版后台，请在原网页点击“关闭后台”，再打开程序。关闭浏览器标签不会停止后台，仍通过网页右上角“关闭后台”退出。

程序版配置保存在 `~/Library/Application Support/LocalRoutePanel/routes.json`，运行日志在该目录的 `logs/app.log`。本次打包已将原项目现有记录复制到专用目录，未覆盖已有程序版配置。源码模式仍使用项目的 `data/routes.json`；后续两种模式的记录分别保存，建议日常使用程序版。

程序采用本机临时签名，未进行 Developer ID 签名或 Apple 公证；当前版本面向本机使用，尚未验证 Intel Mac 或其他 macOS 版本。修改系统路由仍会弹出 macOS 管理员授权，后台本身以普通用户运行。

重新打包：双击 `打包.command`，或运行 `.venv/bin/python -m PyInstaller --noconfirm RoutePanel.spec`。首次打包需要下载 `requirements-build.txt` 中的打包依赖，输出到 `dist/`。

### 源码启动

双击本目录的 **启动.command**。第一次使用如尚未安装依赖，会在本目录创建 `.venv` 并安装 `requirements.txt` 中的固定版本。随后自动打开浏览器。

也可在终端中进入项目目录后运行：

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python run.py
```

访问 http://127.0.0.1:8765 。指定其他端口：`.venv/bin/python run.py --port 8766`。仅以普通用户启动，不使用 sudo 运行整个后台。

关闭网页标签不会停止后台。点击右上角 **关闭后台**，或者在启动终端按 Ctrl+C，可以停止本应用的后台服务。停止后台不会撤销已经写入系统的路由，也不会影响其他 Python 进程。

## 使用

- **路由开关**：先预览影响和命令，再确认并通过 macOS 管理员授权。授权取消或执行失败会保留真实状态，不显示虚假成功。
- **网卡保存的额外路由**：开启/关闭时同步更新该网络服务的额外路由列表，保留其他规则，并按需要同步运行时路由。
- **临时/隧道路由**：调用系统 route 命令。其他软件可能自动恢复被删除的路由，刷新后会标注重新出现。
- **未生效**：配置仍处于开启状态，但实际路由不存在，例如网卡未连接；可关闭再开启以重新应用。
- **添加路由**：支持 IPv4 主机和网段；选择网关或当前可用的 utun 隧道接口。新增是临时系统路由，重启后可以从本地配置手动恢复，不安装开机服务。
- **系统基础路由**：默认、物理接口直连、回环、广播、组播等只读。ARP 邻居与克隆缓存不放入开关列表。

添加 `198.18.4.136 → 198.18.0.204` 这样的规则，只负责让本机把目标数据包交给指定网关。网关还须具备到目标的转发能力与正确回程路由/NAT。界面路径示意不代表连通性测试。

## 本地配置与权限

`data/routes.json` 保存已关闭和新增的规则，采用临时文件、fsync 和原子替换写入。删除它会失去已关闭路由的恢复记录，但不会自动更改系统路由。修改前保存恢复信息，授权后再次检查系统配置，失败时尝试恢复。

服务只监听 `127.0.0.1`，校验 Host、Origin 和本次启动的会话令牌，不开启跨站访问。浏览器不能提交任意命令；管理员助手只处理固定的路由操作。

修改时会调用 AppleScript 的管理员授权。请从正常 macOS 终端或 `启动.command` 启动；受限执行环境可能禁止系统授权或路由套接字访问。程序不会自动设置免密 sudo。

关闭后台按钮在路由修改期间不可用。后端正常停止后，前端显示“后台已关闭”。再次双击启动文件即可使用。

## 测试

```bash
.venv/bin/python -B -m unittest discover -s tests -v
```

测试模拟系统读写和管理员执行，不修改本机真实路由。HTTP 集成测试使用临时配置目录和本机临时端口。

## 文件

- `run.py`：启动 Uvicorn 并打开浏览器，接收正常停止请求。
- `app.py`：网页/API、会话检查、预览、配置保存和管理员助手调用。
- `routing.py`：系统路由/网络服务读取、校验、命令生成、修改与失败恢复。
- `privileged.py`：经过管理员授权执行一次路由操作，执行后退出。
- `static/`：网页、样式、JavaScript 和图标。
- `requirements.in` / `requirements.txt`：直接依赖声明 / 本次安装锁定的完整依赖。
- `RoutePanel.spec` / `requirements-build.txt` / `打包.command`：macOS 应用打包配置、依赖和入口。
